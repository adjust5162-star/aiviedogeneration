# 권리와 워터마크 정책

- 업로드한 영상, 이미지, 음악, 목소리, 얼굴, 로고와 캐릭터의 소유권 또는 사용 허가를 확인해야 합니다.
- 얼굴·목소리 복제는 별도 명시적 동의 없이는 활성화하지 않습니다.
- 워터마크가 있는 원본은 기본적으로 보존하고 경고를 표시합니다.
- 공식 클린 내보내기 옵션이나 명시적 라이선스가 없는 워터마크 제거·가림·크롭은 지원하지 않습니다.
- DRM 우회, 세션 쿠키 재사용, 숨은 URL 스크래핑, 로그인 자동화를 지원하지 않습니다.
- 미성년자 성적 콘텐츠, 비동의 친밀 이미지, 사기성 사칭, 기만적 정치 미디어 요청은 차단 대상입니다.
- 필요하면 “AI 생성” 표시 슬레이트와 메타데이터를 내보내기에 포함하세요.
